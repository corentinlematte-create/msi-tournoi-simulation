# Moteur de modélisation et de gestion de tournois e-sport

Système complet de gestion de compétitions et de tournois en Python, conçu selon les principes de la **programmation orientée objet (POO)**, avec typage statique, contrôle qualité automatisé et suite de tests unitaires.

Ce projet a été réalisé dans le cadre du module *Introduction à la programmation orientée objet, à la documentation et aux tests* à l'**ENSAI** (2025/2026), en prenant pour cas d'application concret la modélisation du format compétitif du **MSI 2024** (*Mid-Season Invitational* — phases de Play-In et Bracket).
